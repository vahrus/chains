# Chains — генератор аналитического отчёта

Учебный проект демонстрирует использование цепочки запросов
(Chains) с помощью Python, LangChain и OpenAI API.

## Задача

Пользователь задаёт тему аналитического отчёта.
Программа последовательно выполняет четыре этапа обработки.

## Логика цепочки

### 1. Анализ задачи

Модель анализирует исходную тему и определяет:

- цель отчёта;
- целевую аудиторию;
- ключевые вопросы;
- ожидаемый результат.

### 2. Подбор структуры

На основании результатов первого этапа модель создаёт
структуру будущего отчёта и определяет содержание разделов.

### 3. Реализация

Модель получает тему, результаты анализа и структуру,
после чего генерирует черновик аналитического отчёта.

### 4. Проверка / ревью

Отдельный запрос используется для проверки черновика.
Модель оценивает соответствие теме, структуру, повторы,
понятность выводов и стиль, после чего формирует
финальную версию.

## Схема цепочки

Тема пользователя
↓
Анализ задачи
↓
Формирование структуры
↓
Генерация отчёта
↓
Проверка и улучшение
↓
Финальный отчёт
